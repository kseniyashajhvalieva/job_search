
## Установка и запуск

1. **Клонирование и переход в директорию**
2. **Установка зависимостей** (Poetry или pip)
3. **Настройка переменных окружения**: скопируй `.env_template` в `.env` и укажи свои данные для подключения к PostgreSQL
4. **Запуск:** `python main.py`

## Функциональности

* Получение информации о 10 выбранных работодателях и их вакансиях через API hh.ru
* Автоматическое создание базы данных `hh_parser` и таблиц `employers`, `vacancies`
* Сохранение данных в PostgreSQL
* Методы класса `DBManager` для аналитических запросов:
  - список компаний с количеством вакансий
  - все вакансии с указанием названия компании, зарплаты и ссылки
  - средняя зарплата по вакансиям
  - вакансии с зарплатой выше средней
  - поиск вакансий по ключевому слову

## Инструменты

- Python 3.13
- requests, psycopg2-binary, python-dotenv
- pytest, flake8, black, isort, mypy
- PostgreSQL
